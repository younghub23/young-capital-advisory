# Young Capital Advisory

A sleek, professional single-page website for Young Capital Advisory, a commercial real estate financial modeling consultancy.

## Overview

This website features:
- Dark mode design with deep navy/charcoal palette
- Muted gold accent color for CTAs and highlights
- Modern sans-serif typography (Inter)
- Smooth scroll animations
- Mobile-responsive layout
- Clean, minimal aesthetic

## Structure

```
young-capital-advisory/
├── index.html          # Main HTML file
├── css/
│   └── styles.css      # All styles
├── js/
│   └── script.js       # Animations & interactions
└── README.md
```

## Sections

1. **Hero** - Main headline with CTA
2. **Services** - Five service offerings in card layout
3. **About** - Company overview with geometric visuals
4. **Contact** - Contact form and details
5. **Footer** - Minimal copyright

## Deployment

### Vercel

```bash
npm i -g vercel
vercel
```

### Netlify

1. Connect your repository to Netlify
2. Build command: (leave empty)
3. Publish directory: `/`

### Manual

Simply upload all files to any static hosting service.

## Development

This is a static HTML/CSS/JS site. No build step required.

To run locally, use any static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```
